Zer da Wokwi

Wokwi nabigatzailean dabilen elektronika-simulagailu bat da. Plaka bat aukeratzen duzu (ESP32, Arduino, Raspberry Pi Pico…), sentsoreak, LEDak edo pantailak gehitzen dituzu, kableak lotzen dituzu eta zure programa exekutatzen duzu plaka erreala balitz bezala. Firmwarea gero hardwarean kargatuko duzun bera da.

IoT-rako baliagarria da ESP32 simulatuak WiFi-a duelako: Internetera konekta daiteke, eta Pro lizentziarekin zure ordenagailuan dabiltzan zerbitzuetara ere bai, MQTT broker-era eta Node-RED-era kasu.

Datuen bidea

Martxan jartzea (lehen aldian bakarrik)

  1. Mosquitto Docker-en

    Sortu karpeta bat fitxategi honekin. Mosquitto 2-k ez ditu kanpoko konexioak onartzen esaten ez badiozu:

    mosquitto.conf
    listener 1883
allow_anonymous true

    Karpeta horretatik, PowerShell-en:

    PowerShell
    docker run -d --name mosquitto --restart unless-stopped -p 1883:1883 -v ${PWD}/mosquitto.conf:/mosquitto/config/mosquitto.conf eclipse-mosquitto:2

    Egiaztatu: docker ps-k mosquitto erakusten du 0.0.0.0:1883->1883/tcp-rekin.

  2. Node-RED Docker-en eta dashboard paleta

    PowerShell
    docker run -d --name nodered --restart unless-stopped -p 1880:1880 -v nodered_data:/data nodered/node-red

    Ireki http://localhost:1880 → ☰ menua → Manage palette → Install → bilatu @flowfuse/node-red-dashboard → Install. Dashboard 2.0 da; ez instalatu node-red-dashboard zaharra.

  3. Wokwi IoT Gateway

    1. Deskargatu Windows-erako azken bertsioa: github.com/wokwi/wokwigw/releases.
    2. Deskonprimitu eta exekutatu wokwigw.exe (Windows-ek abisatzen badu, utzi exekutatzen; ez du administratzaile-baimenik behar).
    3. Listening on TCP port 9011 agertu behar da. Utzi leihoa irekita lanean zauden bitartean.
    4. Wokwi-ko editorean sakatu F1 → Enable Private Wokwi IoT Gateway → OK.

    Egiaztatu: simulazio bat abiaraztean, gateway-aren leihoan Client connected agertzen da. Ez dabil Safari-n.

  4. Sarearen konfigurazioa sketch-ean

    sketch.ino
    const char* WIFI_SSID = "Wokwi-GUEST";            // simulagailuaren sare bakarra
const char* WIFI_PASS = "";                       // pasahitzik gabe
const char* MQTT_HOST = "host.wokwi.internal";    // = zure PCa, gateway-ari esker
const uint16_t MQTT_PORT = 1883;

WiFi.begin(WIFI_SSID, WIFI_PASS, 6);              // 6 = kanala: Wokwi-n azkarrago konektatzen da

    Ez jarri ikasgelako WiFi erreala Wokwi-n. ESP32 simulatuak ez du ikusten eta ez da konektatuko. Gainera, pasahitza parteka daitekeen proiektu batean idatzita geratuko litzateke.

  5. Broker-aren konfigurazioa Node-RED-en

    mqtt in eta mqtt out nodo guztiek konfigurazio-nodo bera erabiltzen dute, Mosquitto local:

    EremuaBalioaZergatik
    Serverhost.docker.internalNode-RED edukiontzi batean dago: han localhost edukiontzia bera da, ez zure PCa. Node-RED Docker gabe instalatu baduzu, erabili localhost.
    Port1883Mosquitto-ren ataka.
    Output (mqtt in)a parsed JSON objectHorrela msg.payload objektu gisa iristen da, ez testu gisa.

    Egiaztatu: MQTT nodo bakoitzaren azpian connected agertzen da berdez.

  6. Fluxu bat inportatu

    ☰ menua → Import → itsatsi JSON-a (edo hautatu fitxategia) → Import → Deploy. Webgune honetako fluxuek broker-a eta dashboard-a konfiguratuta dakartzate.

    Proiektu bat beste baten ondoren inportatzen baduzu, Node-RED-ek abisatuko du nodo batzuk badaudela (broker-a eta dashboard-a): aukeratu Replace. Berdin-berdinak dira.

  2. Programa

    Ordeztu sketch.ino. Programa WiFi-ra eta broker-era konektatzen da, 5 s-ro argitaratzen du eta LEDaren aginduak betetzen ditu. Azken nahiaren mezuari (LWT) esker, broker-ak offline argitaratzen du ESP32-a desagertzen bada.

    sketch.inoESP32 → MQTT
    sketch.ino
    // ============================================================================
//  ENV III simulado (DHT22 = temperatura/humedad, BMP180 = presión) → MQTT
//  CIFP Don Bosco LHII
//
//  Publica cada 5 s en  mantetwin/env3/telemetry  (JSON)
//  Escucha el LED en    mantetwin/env3/led        ("on" / "off")
//  Estado (LWT)         mantetwin/env3/status     ("online" / "offline")
// ============================================================================
#include <WiFi.h>
#include <Wire.h>
#include <PubSubClient.h>
#include <DHT.h>
#include <Adafruit_BMP085.h>

#define DHT_PIN 4
#define LED_PIN 2

const char* WIFI_SSID = "Wokwi-GUEST";
const char* WIFI_PASS = "";
// Con el Private IoT Gateway, host.wokwi.internal es TU ordenador (donde corre Mosquitto)
const char* MQTT_HOST = "host.wokwi.internal";
const uint16_t MQTT_PORT = 1883;

const char* T_TELE   = "mantetwin/env3/telemetry";
const char* T_LED    = "mantetwin/env3/led";
const char* T_STATUS = "mantetwin/env3/status";

DHT dht(DHT_PIN, DHT22);
Adafruit_BMP085 bmp;
bool bmpOk = false;

WiFiClient net;
PubSubClient mqtt(net);
unsigned long lastSend = 0;

void onMessage(char* topic, byte* payload, unsigned int len) {
  String msg;
  for (unsigned int i = 0; i < len; i++) msg += (char)payload[i];
  msg.trim();
  Serial.printf("<- %s: %s\n", topic, msg.c_str());
  if (String(topic) == T_LED) {
    bool on = (msg == "on" || msg == "1" || msg == "true");
    digitalWrite(LED_PIN, on ? HIGH : LOW);
  }
}

void connectWiFi() {
  Serial.print("WiFi");
  WiFi.begin(WIFI_SSID, WIFI_PASS, 6);   // en hardware real: WiFi.begin(SSID, PASS);
  while (WiFi.status() != WL_CONNECTED) { delay(250); Serial.print("."); }
  Serial.printf(" OK (IP %s)\n", WiFi.localIP().toString().c_str());
}

void connectMQTT() {
  while (!mqtt.connected()) {
    Serial.printf("MQTT %s:%u ... ", MQTT_HOST, MQTT_PORT);
    // Last Will: si el ESP32 desaparece, el broker publica "offline"
    if (mqtt.connect("env3-wokwi", T_STATUS, 1, true, "offline")) {
      Serial.println("OK");
      mqtt.publish(T_STATUS, "online", true);
      mqtt.subscribe(T_LED);
    } else {
      Serial.printf("error rc=%d, reintento en 2 s\n", mqtt.state());
      delay(2000);
    }
  }
}

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  dht.begin();
  Wire.begin(21, 22);
  bmpOk = bmp.begin();
  Serial.println(bmpOk ? "BMP180 OK" : "BMP180 no encontrado");

  connectWiFi();
  mqtt.setServer(MQTT_HOST, MQTT_PORT);
  mqtt.setCallback(onMessage);
  connectMQTT();
}

void loop() {
  if (WiFi.status() != WL_CONNECTED) connectWiFi();
  if (!mqtt.connected()) connectMQTT();
  mqtt.loop();

  if (millis() - lastSend < 5000) return;
  lastSend = millis();

  float t = dht.readTemperature();
  float h = dht.readHumidity();
  float p = bmpOk ? bmp.readPressure() / 100.0 : NAN;   // Pa → hPa

  if (isnan(t) || isnan(h)) {
    Serial.println("DHT22: lectura fallida");
    return;
  }

  char js[128];
  snprintf(js, sizeof js, "{\"t\":%.1f,\"h\":%.1f,\"p\":%s,\"led\":%d}",
           t, h, isnan(p) ? "null" : String(p, 1).c_str(), digitalRead(LED_PIN));
  mqtt.publish(T_TELE, js);
  Serial.printf("-> %s\n", js);
}

Arazoa: deriba

Deriba duen sentsore batek funtzionatzen jarraitzen du eta balio sinesgarriak ematen ditu, baina gero eta urrunago benetako baliotik. Ez da bat-bateko hutsegite bat: motela da eta ez da bere kabuz zuzentzen. Zahartzen diren tenperatura-sentsoreekin edo hezetasuna hartzen duten pisaketa-zelulekin gertatzen da.

Sentsore bakarrari begiratuta ezin da detektatu: tenperatura gehiago markatzen badu, ez dakigu gela berotu den edo sentsorea desbideratzen ari den. Irtenbidea ondoan erreferentziako sentsore bat jartzea da. Biak batera igotzen badira, giroa da; bakarra igotzen bada, deriba.

Bi adimen-maila

ESP32 (Edge): nola dago orain?

Bi sentsoreak konparatzen ditu 2 s-ro eta LED bat pizten du desbideratzeak atalase bat gainditzen badu. Oraingo balioari erantzuten dio, saretik independente.

  • Aldea dT = nagusia − erreferentzia
  • Zarata kentzeko iragazkia
  • Egoerak: OK, DRIFT_WARN, DRIFT_ALARM

Node-RED (zerbitzaria): nora doa?

Azken minutuak gordetzen ditu, zuzen bat doitzen du eta alarma-atalasera noiz iritsiko den estrapolatzen du. ESP32-ak ezer ikusi aurretik abisatzen du.

  • Deriba-abiadura (°C/min) eta fidagarritasuna (R²)
  • RUL: alarmara arteko minutuak
  • Egoerak: OK, TREND, WARN, ALARM

Hori da mantentze zuzentzailearen (hondatzen denean konpondu), prebentiboaren (egutegiaren arabera aldatu) eta prediktiboaren (datuek hutsegitea iragartzen dutenean jardun) arteko aldea. Proiektu hau prediktiboa da.

Wokwi-k ez du SHT30-a, beraz C-n programatu dugu. Sentsore errealaren I2C komando berberei erantzuten die, formatu eta CRC berarekin; horregatik firmwareak ENV III errealarekin ere balio du. Gainera, hutsegiteak eragiteko kontrolak ditu. Klik egin chip-ean simulazioan ikusteko:

    // ============================================================================
//  SHT30 ManteTwin - Wokwi custom chip
//  CIFP Don Bosco LHII - ManteTwin (Tknika 2026-27)
//
//  M5Stack ENV III-ko SHT30 sentsorea emulatzen du (I2C, 0x44 / 0x45),
//  akatsak injektatzeko aukerarekin. Simulazioan txipean klik eginda
//  kontrolak agertzen dira:
//
//    temperature  : tenperatura "erreala" (°C)
//    humidity     : hezetasun erlatiboa (%)
//    driftRate    : deriba-abiadura (°C/min). Offseta metatu egiten da eta
//                   ez da berreskuratzen (sentsore errealetan bezala).
//    faultMode    : 0 = normala
//                   1 = blokeatuta (azken balioa izoztuta)
//                   2 = hilda (ez du I2C ACK-rik ematen)
//                   3 = intermitentea (konektore solte: ~%20 NACK)
//                   4 = bus-zarata (CRC okerrak ~%50)
//
//  FLT pina: HIGH akatsen bat aktibo dagoenean (driftRate > 0 edo
//  faultMode != 0). Dataseta etiketatzeko "ground truth" gisa erabiltzen da.
//
//  diagram.json-eko "address" atributua: 68 (0x44) edo 69 (0x45).
// ============================================================================

#include "wokwi-api.h"
#include <stdio.h>
#include <stdlib.h>

enum {
  FAULT_NONE = 0,
  FAULT_STUCK = 1,
  FAULT_DEAD = 2,
  FAULT_INTERMITTENT = 3,
  FAULT_CRC = 4
};

typedef struct {
  pin_t pin_flt;
  uint32_t attr_temp;
  uint32_t attr_hum;
  uint32_t attr_drift;
  uint32_t attr_fault;
  float drift_offset;      // metatutako deriba (°C)
  uint8_t cmd[2];
  uint8_t cmd_len;
  uint8_t out[6];          // T_MSB T_LSB CRC H_MSB H_LSB CRC
  uint8_t out_idx;
  uint16_t last_raw_t;
  uint16_t last_raw_h;
  bool has_last;
  uint32_t rng;
} chip_state_t;

// Ausazko zenbaki sinplea (0..1)
static float rnd(chip_state_t *c) {
  c->rng = c->rng * 1103515245u + 12345u;
  return (float)((c->rng >> 8) & 0xFFFF) / 65535.0f;
}

// SHT3x CRC-8 (polinomioa 0x31, hasiera 0xFF)
static uint8_t crc8(const uint8_t *d, int n) {
  uint8_t crc = 0xFF;
  for (int i = 0; i < n; i++) {
    crc ^= d[i];
    for (int b = 0; b < 8; b++) {
      crc = (crc & 0x80) ? (uint8_t)((crc << 1) ^ 0x31) : (uint8_t)(crc << 1);
    }
  }
  return crc;
}

static int fault_mode(chip_state_t *c) {
  return (int)(attr_read_float(c->attr_fault) + 0.5f);
}

static uint16_t to_raw(float v) {
  if (v < 0) v = 0;
  if (v > 65535) v = 65535;
  return (uint16_t)(v + 0.5f);
}

static void prepare_measurement(chip_state_t *c) {
  int f = fault_mode(c);
  uint16_t rt, rh;

  if (f == FAULT_STUCK && c->has_last) {
    // Blokeatuta: azken neurketa errepikatu, zaratarik gabe
    rt = c->last_raw_t;
    rh = c->last_raw_h;
  } else {
    // Sentsore errealek zarata txikia dute: horri esker detektatzen da blokeoa
    float t = attr_read_float(c->attr_temp) + c->drift_offset + (rnd(c) - 0.5f) * 0.10f;
    float h = attr_read_float(c->attr_hum) + (rnd(c) - 0.5f) * 0.40f;
    if (h < 0) h = 0;
    if (h > 100) h = 100;
    rt = to_raw((t + 45.0f) * 65535.0f / 175.0f);
    rh = to_raw(h * 65535.0f / 100.0f);
    c->last_raw_t = rt;
    c->last_raw_h = rh;
    c->has_last = true;
  }

  c->out[0] = rt >> 8;
  c->out[1] = rt & 0xFF;
  c->out[2] = crc8(&c->out[0], 2);
  c->out[3] = rh >> 8;
  c->out[4] = rh & 0xFF;
  c->out[5] = crc8(&c->out[3], 2);

  if (f == FAULT_CRC && rnd(c) < 0.5f) {
    c->out[2] ^= 0x5A;   // bus-zarata: CRC hondatua
  }
  c->out_idx = 0;
}

// ---------------- I2C ----------------
static bool on_i2c_connect(void *user_data, uint32_t address, bool read) {
  chip_state_t *c = user_data;
  int f = fault_mode(c);
  if (f == FAULT_DEAD) return false;                              // NACK beti
  if (f == FAULT_INTERMITTENT && rnd(c) < 0.20f) return false;    // NACK batzuetan
  if (!read) c->cmd_len = 0;
  return true;
}

static bool on_i2c_write(void *user_data, uint8_t data) {
  chip_state_t *c = user_data;
  if (c->cmd_len < 2) c->cmd[c->cmd_len++] = data;
  if (c->cmd_len == 2) {
    uint8_t msb = c->cmd[0];
    // 0x24xx = single shot (clock stretching gabe), 0x2Cxx = clock stretchingarekin
    if (msb == 0x24 || msb == 0x2C) prepare_measurement(c);
  }
  return true;
}

static uint8_t on_i2c_read(void *user_data) {
  chip_state_t *c = user_data;
  uint8_t v = (c->out_idx < 6) ? c->out[c->out_idx] : 0xFF;
  c->out_idx++;
  return v;
}

static void on_i2c_disconnect(void *user_data) {
  (void)user_data;
}

// ---------------- Denbora (100 ms) ----------------
static void on_tick(void *user_data) {
  chip_state_t *c = user_data;
  float rate = attr_read_float(c->attr_drift);   // °C/min
  if (rate > 0.0f) c->drift_offset += rate / 600.0f;
  bool active = (fault_mode(c) != FAULT_NONE) || (rate > 0.001f);
  pin_write(c->pin_flt, active ? HIGH : LOW);
}

void chip_init(void) {
  chip_state_t *c = calloc(1, sizeof(chip_state_t));

  c->attr_temp  = attr_init_float("temperature", 24.0f);
  c->attr_hum   = attr_init_float("humidity", 45.0f);
  c->attr_drift = attr_init_float("driftRate", 0.0f);
  c->attr_fault = attr_init_float("faultMode", 0.0f);
  uint32_t address = attr_read(attr_init("address", 0x44));

  c->pin_flt = pin_init("FLT", OUTPUT_LOW);
  c->rng = 0xC0FFEEu + address;

  const i2c_config_t i2c_config = {
    .user_data = c,
    .address = address,
    .scl = pin_init("SCL", INPUT),
    .sda = pin_init("SDA", INPUT),
    .connect = on_i2c_connect,
    .read = on_i2c_read,
    .write = on_i2c_write,
    .disconnect = on_i2c_disconnect,
  };
  i2c_init(&i2c_config);

  const timer_config_t timer_config = {
    .callback = on_tick,
    .user_data = c,
  };
  timer_t t = timer_init(&timer_config);
  timer_start(t, 100000, true);   // 100 ms

  printf("SHT30 ManteTwin prest, helbidea 0x%02X\n", (unsigned)address);
}

// ---------------- SHT30 irakurketa ----------------
enum ReadResult { RD_OK, RD_NACK, RD_CRC };

uint8_t crc8(const uint8_t* d, int n) {
  uint8_t crc = 0xFF;
  for (int i = 0; i < n; i++) {
    crc ^= d[i];
    for (int b = 0; b < 8; b++) crc = (crc & 0x80) ? (crc << 1) ^ 0x31 : (crc << 1);
  }
  return crc;
}

ReadResult sht30Read(uint8_t addr, float& t, float& h, uint16_t& rawT) {
  Wire.beginTransmission(addr);
  Wire.write(0x24);
  Wire.write(0x00);                       // single shot, errepikakortasun altua
  if (Wire.endTransmission() != 0) return RD_NACK;
  delay(16);
  if (Wire.requestFrom((int)addr, 6) != 6) return RD_NACK;
  uint8_t b[6];
  for (int i = 0; i < 6; i++) b[i] = Wire.read();
  if (crc8(b, 2) != b[2] || crc8(b + 3, 2) != b[5]) return RD_CRC;
  rawT = ((uint16_t)b[0] << 8) | b[1];
  uint16_t rawH = ((uint16_t)b[3] << 8) | b[4];
  t = -45.0f + 175.0f * rawT / 65535.0f;
  h = 100.0f * rawH / 65535.0f;
  return RD_OK;
}

void onMessage(char* topic, byte* payload, unsigned int len) {

  String msg;
  for (unsigned int i = 0; i < len; i++) msg += (char)payload[i];

// ---------------- Loop ----------------
void loop() {
  unsigned long now = millis();

#if SCENARIO == 5
  // --- Akatsen injekzioa (potentziometroak eta etengailua) ---
  attDb   = analogRead(PIN_POT_ATT)  * 40.0f / 4095.0f;
  lossPct = analogRead(PIN_POT_LOSS) * 50.0f / 4095.0f;
  bool linkCut = digitalRead(PIN_SW_LINK) == HIGH;

  if (linkCut) {
    // Ez dugu mqtt.loop() deitzen: keepalive-a iraungi eta brokerrak LWT bidaltzen du
    if (!linkWasCut) {
      linkWasCut = true;
      linkCutSince = now;
      Serial.println("!! Lotura etenda (simulatua)");
    }
    setLeds(true, true);
    delay(50);
    return;
  }
  if (linkWasCut) {
    // Berreskurapena: konexio berria eta etenaldiaren gertaera (store & forward)
    unsigned long outage = now - linkCutSince;
    linkWasCut = false;
    mqtt.disconnect();
    mqttConnect();
    mqtt.publish(T_EVENT.c_str(),
                 (String("{\"event\":\"link_restored\",\"outage_ms\":") + outage + "}").c_str());
  }
#endif

  if (WiFi.status() != WL_CONNECTED) wifiConnect();
  if (!mqtt.connected()) mqttConnect();
  mqtt.loop();

#if SCENARIO == 5
  // Ping atzeratua askatu
  if (pendingPing && now >= pendingRelease) {
    pendingPing = false;
    float rtt = (float)(now - pendingSentAt);
    rttEma = (rttEma < 0) ? rtt : 0.8f * rttEma + 0.2f * rtt;
    pingRecv++;
  }
  // Ping bat 2 segundoan behin (galera-tasa eta latentzia neurtzeko)
  if (now - lastPing >= 2000) {
    lastPing = now;
    pingSent++;
    publishTele(T_PING, String(now));
  }
#endif

  if (now - lastTele < telemetryInterval) return;
  lastTele = now;
  seq++;

  float t = NAN, h = NAN;
  uint16_t rawT = 0;
  ReadResult r = sht30Read(ADDR_MAIN, t, h, rawT);
  if (r == RD_NACK) i2cNack++;
  if (r == RD_CRC)  i2cCrc++;

  String st = "OK";
  bool injected = digitalRead(PIN_FLT) == HIGH;
  String extra;

#if SCENARIO == 1
  // ---- Deriba: sentsore nagusia erreferentziarekin konparatu ----
  float tr = NAN, hr = NAN;
  uint16_t rawR = 0;
  ReadResult rr = sht30Read(ADDR_REF, tr, hr, rawR);
  if (r == RD_OK && rr == RD_OK) {
    float dT = t - tr;
    dTema = 0.9f * dTema + 0.1f * dT;
    if (fabs(dTema) > DRIFT_ALARM)     st = "DRIFT_ALARM";
    else if (fabs(dTema) > DRIFT_WARN) st = "DRIFT_WARN";
    extra = String(",\"t_ref\":") + String(tr, 2) +
            ",\"dT\":" + String(dT, 3) + ",\"dT_ema\":" + String(dTema, 3);
  } else {
    st = "SENSOR_ERR";
  }
#endif

#if SCENARIO == 2
  // ---- Sentsore blokeatua / I2C ----
  winReads++;
  if (r == RD_NACK) winNack++;
  if (r == RD_CRC)  winCrc++;
  if (winReads >= 30) { winReads /= 2; winNack /= 2; winCrc /= 2; }   // leiho "leuna"
  float nackRatio = (float)winNack / (float)winReads;
  float crcRatio  = (float)winCrc  / (float)winReads;

  if (r == RD_OK) {
    lastRaw[rawIdx] = rawT;
    rawIdx = (rawIdx + 1) % STUCK_N;
    if (rawCount < STUCK_N) rawCount++;
  }
  bool stuck = false;
  if (rawCount == STUCK_N) {
    stuck = true;
    for (int i = 1; i < STUCK_N; i++) if (lastRaw[i] != lastRaw[0]) { stuck = false; break; }
  }

  if (nackRatio > 0.8f)       st = "SENSOR_DEAD";
  else if (stuck)             st = "STUCK";
  else if (crcRatio > 0.10f)  st = "BUS_NOISE";
  else if (nackRatio > 0.05f) st = "INTERMITTENT";
  extra = String(",\"nack_ratio\":") + String(nackRatio, 3) +
          ",\"crc_ratio\":" + String(crcRatio, 3) + ",\"stuck\":" + (stuck ? 1 : 0);
#endif

#if SCENARIO == 5
  // ---- Komunikazioak ----
  int rssi = WiFi.RSSI() - (int)attDb;
  float pingLoss = (pingSent > 0) ? 1.0f - (float)pingRecv / (float)pingSent : 0;
  if (pingSent >= 20) { pingSent /= 2; pingRecv /= 2; }  // leiho leuna
  if (pingLoss > 0.10f)  st = "PACKET_LOSS";
  else if (rssi < -80)   st = "WEAK_SIGNAL";
  else if (rttEma > 300) st = "HIGH_LATENCY";
  injected = (attDb > 20) || (lossPct > 5);
  extra = String(",\"rssi\":") + rssi + ",\"rtt_ms\":" + String(rttEma, 0) +
          ",\"ping_loss\":" + String(pingLoss, 3) + ",\"tx_dropped\":" + txDropped +
          ",\"att_db\":" + String(attDb, 1) + ",\"loss_inj\":" + String(lossPct, 1);
#endif

  bool detected = (st != "OK");
  setLeds(detected, injected);

  String js = String("{\"node\":\"") + NODE_ID + "\",\"scn\":" + SCENARIO +
              ",\"seq\":" + seq + ",\"up_ms\":" + now +
              ",\"t\":" + (isnan(t) ? String("null") : String(t, 2)) +
              ",\"h\":" + (isnan(h) ? String("null") : String(h, 1)) +
              ",\"st\":\"" + st + "\"" +
              ",\"i2c_nack\":" + i2cNack + ",\"i2c_crc\":" + i2cCrc +
              ",\"reconn\":" + reconnects +
              extra +
              ",\"label\":" + (injected ? 1 : 0) + "}";

  publishTele(T_TELE, js);
  Serial.println(js);
}

  2. Node-RED-ek zer kalkulatzen duen

    Tendencia + RUL funtzioak bost gauza egiten ditu mezu bakoitzarekin:

    1. 5 minutuko leihoa: azken 5 minutuetako dT_ema balioak gordetzen ditu (150 lagin inguru) eta zaharrenak baztertzen ditu.
    2. Karratu txikienen zuzena: y = a + b·x doitzen die puntuei. b malda deriba-abiadura da, °C/min-tan.
    3. Doikuntzaren kalitatea (R²): 0 eta 1 artean. 1etik gertu, puntuek zuzen argi bat jarraitzen dute; 0tik gertu, zarata besterik ez dago. Joeraz fidatzen da R² ≥ 0,6 bada, malda 0,01 °C/min baino handiagoa bada eta gutxienez 15 lagin badaude.
    4. RUL (Remaining Useful Life, gelditzen den bizitza erabilgarria):

    RUL = (1,5 °C − |dT_ema|) ÷ malda   → alarmara arteko minutuak
    Osasuna = 100 · (1 − |dT_ema| ÷ 1,5)   → %

    1. Egoera eta alertak: egoera bat esleitzen du eta alerta bat argitaratzen du aldatzen denean bakarrik.
    Egoera (zerbitzaria)Baldintza
    OKDesbideratzea < 0,5 °C eta joera argirik gabe
    TRENDOraindik < 0,5 °C, baina joera fidagarriarekin eta RUL < 30 min. Hemen zerbitzaria ESP32-aren aurretik doa.
    WARNDesbideratzea ≥ 0,5 °C
    ALARMDesbideratzea ≥ 1,5 °C → birkalibratu edo ordeztu

    Desbideratzea positiboa edo negatiboa izan daiteke: kalkuluak balio absolutua eta «kanporako» malda erabiltzen ditu, eta bi noranzkoetan dabil. ESP32-a berrabiarazten bada (seq zenbakia berriz hasten da), historia ezabatzen da.

Nola dabilen, pausoz pauso

  1. Neurtu: 200 lagin segundoko

    MPU6050-ak hiru ardatzetako azelerazioa neurtzen du (X, Y, Z). ESP32-ak 5 ms-ro irakurtzen du (200 Hz), ±4 g-ko tartean eta barne-iragazkia 94 Hz-tan duela. 200 Hz-rekin 100 Hz arteko bibrazioak ikus daitezke (erdia, Nyquist-en teoremagatik): nahikoa 1500 rpm-ko motor baten desoreka eta lerrokatze-akatsa ikusteko.

  2. Laburtu: segundo bateko leihoa

    Ez du zentzurik segundoko 200 datu WiFi bidez bidaltzeak. ESP32-ak 200 lagin biltzen ditu (1 s) eta bibrazio hori deskribatzen duten zenbaki gutxi batzuk kalkulatzen ditu:

  4. Normala ikasi: lehen 30 segundoak

    Motor bakoitzak desberdin bibratzen du bere tamainaren, ainguraketaren edo kargaren arabera, beraz ez dago muga unibertsalik. Node-RED-ek ikasi egiten du nola bibratzen duen motor honek osasuntsu dagoenean: lehen 30 RMS balioekin batez bestekoa μ eta desbideratze estandarra σ kalkulatzen ditu (segundo batetik bestera zenbat aldatzen den). Welford-en algoritmoarekin egiten du: batez bestekoa eta bariantza datuz datu eguneratzen ditu, zerrenda osoa gorde gabe.

    Ikasten ari den bitartean, egoera IKASTEN da: LED berdea eta horia batera. Horregatik motorrak egoera onean egon behar du abiaraztean, potentziometroa 0-n dagoela.

  5. Erabaki: mugekin konparatu

    Ikasitakoarekin bi muga estatistiko kalkulatzen ditu:

    ABISUA = μ + 3σ
    ALARMA = μ + 6σ

    Bibrazioa normala bada, oso arraroa da μ + 3σ kasualitatez gainditzea, eta μ + 6σ ia ezinezkoa. Gertatzen bada, motorrean zerbait aldatu da. Gailur isolatu bati ez erantzuteko, azken 5 leihoen batez bestekoa (5 s) konparatzen du, ez balio solte bat.

    Simulazioan zarata hain da egonkorra ezen σ txiki-txikia ateratzen den, eta mugak batez bestekoari itsatsita geratuko lirateke. Horregatik σ-k 0,01 g-ko gutxieneko bat du. Motor osasuntsu batekin (RMS ≈ 0,020 g), mugak 0,050 g eta 0,080 g dira.

  6. Jardun: LEDak, abisuak eta erregistroa

    Egoera aldatzen den bakoitzean, Node-RED-ek:

    • ESP32-ra bidaltzen du (donbosco/mantetwin/motor1/egoera), eta honek NORMALA, ABISUA edo ALARMA pizten du;
    • jakinarazpen bat erakusten du dashboard-ean;
    • lerro bat gehitzen dio /data/mantetwin_motor1_log.csv-ri ordua, egoera, RMS-a eta mugekin. Hori da mantentze-historia.

    Oinarria berrikasi botoiak ikasitakoa ezabatu eta berriz hasten da. Konponketa baten ondoren erabiltzen da, motorra berriz osasuntsu dagoenean.

  ManteTwin - Motor baten mantentze prediktiboa
  ESP32 + MPU6050 -> MQTT -> Node-RED

  - 200 Hz-tan azelerazioa irakurri, 1 s-ko leihoak (200 lagin)
  - Leiho bakoitzeko ezaugarriak: RMS (X, Y, Z eta guztira), gailurra, crest factor, tenperatura
  - JSON-a MQTT bidez bidali  -> donbosco/mantetwin/motor1/datuak
  - Node-RED-en egoera jaso      <- donbosco/mantetwin/motor1/egoera
    (NORMALA = berdea, ABISUA = horia, ALARMA = gorria, IKASTEN = berdea + horia)

  SIMULAZIOA 1: Wokwi-n MPU6050-a ez da bibratzen, beraz potentziometroarekin
  bibrazio sintetikoa gehitzen da (akats bat simulatzeko). Hardware errealean: 0.
*/

#include <WiFi.h>
#include <PubSubClient.h>
#include <Wire.h>
#include <Adafruit_MPU6050.h>
#include <Adafruit_Sensor.h>
#include <ArduinoJson.h>

#define SIMULAZIOA 1

// ---------- Konfigurazioa ----------
const char* WIFI_SSID = "Wokwi-GUEST";
const char* WIFI_PASS = "";

const char* MQTT_HOST = "host.wokwi.internal"; // IoT Gateway -> zure PCko Mosquitto (hardware errealean: PCaren IPa)
const uint16_t MQTT_PORT = 1883;
const char* TOPIC_DATUAK = "donbosco/mantetwin/motor1/datuak";
const char* TOPIC_EGOERA = "donbosco/mantetwin/motor1/egoera";

const int PIN_POT    = 34;   // akatsaren intentsitatea (simulazioa)
const int LED_BERDEA = 25;
const int LED_HORIA  = 26;
const int LED_GORRIA = 27;

const float G = 9.80665f;
const int FS = 200;                              // laginketa-maiztasuna (Hz)
const int N  = 200;                              // leihoa: N / FS = 1 s
const unsigned long PERIOD_US = 1000000UL / FS;

// ---------- Aldagaiak ----------
Adafruit_MPU6050 mpu;
WiFiClient net;
PubSubClient mqtt(net);

float ax[N], ay[N], az[N];
int idx = 0;
float tempC = 0;
unsigned long nextSample = 0;
unsigned long lastReconnect = 0;

// ---------- LEDak ----------
void setLeds(const String& egoera) {
  digitalWrite(LED_BERDEA, egoera == "NORMALA" || egoera == "IKASTEN");
  digitalWrite(LED_HORIA,  egoera == "ABISUA"  || egoera == "IKASTEN");
  digitalWrite(LED_GORRIA, egoera == "ALARMA");
}

void mqttCallback(char* topic, byte* payload, unsigned int len) {
  String egoera;
  for (unsigned int i = 0; i < len; i++) egoera += (char)payload[i];
  egoera.trim();
  Serial.printf("Egoera Node-RED-etik: %s\n", egoera.c_str());
  setLeds(egoera);
}

// ---------- Konexioak ----------
void connectWiFi() {
  Serial.print("WiFi-ra konektatzen");
  WiFi.begin(WIFI_SSID, WIFI_PASS, 6);   // 6 = kanala (Wokwi-n azkarrago). Hardware errealean kendu
  while (WiFi.status() != WL_CONNECTED) { delay(250); Serial.print("."); }
  Serial.printf("\nWiFi OK, IP: %s\n", WiFi.localIP().toString().c_str());
}

bool connectMQTT() {
  String clientId = "mantetwin-motor1-" + String((uint32_t)esp_random(), HEX);
  if (mqtt.connect(clientId.c_str())) {
    mqtt.subscribe(TOPIC_EGOERA);
    Serial.println("MQTT OK");
    return true;
  }
  Serial.printf("MQTT errorea, rc=%d\n", mqtt.state());
  return false;
}

// ---------- Simulazioa ----------
float zarata() { return random(-1000, 1001) / 1000.0f; }

// ---------- Leihoaren prozesamendua ----------
void prozesatuLeihoa() {
  float mx = 0, my = 0, mz = 0;
  for (int i = 0; i < N; i++) { mx += ax[i]; my += ay[i]; mz += az[i]; }
  mx /= N; my /= N; mz /= N;                     // DC osagaia (grabitatea + jarrera)

  float sx = 0, sy = 0, sz = 0, peak = 0;
  for (int i = 0; i < N; i++) {
    float dx = ax[i] - mx, dy = ay[i] - my, dz = az[i] - mz;
    sx += dx * dx; sy += dy * dy; sz += dz * dz;
    float m = sqrtf(dx * dx + dy * dy + dz * dz);
    if (m > peak) peak = m;
  }
  float rx = sqrtf(sx / N), ry = sqrtf(sy / N), rz = sqrtf(sz / N);
  float rms = sqrtf(rx * rx + ry * ry + rz * rz);
  float crest = rms > 0 ? peak / rms : 0;

  JsonDocument doc;
  doc["id"]    = "motor1";
  doc["rms"]   = roundf(rms * 10000) / 10000.0;
  doc["rmsX"]  = roundf(rx * 10000) / 10000.0;
  doc["rmsY"]  = roundf(ry * 10000) / 10000.0;
  doc["rmsZ"]  = roundf(rz * 10000) / 10000.0;
  doc["peak"]  = roundf(peak * 10000) / 10000.0;
  doc["crest"] = roundf(crest * 100) / 100.0;
  doc["temp"]  = roundf(tempC * 10) / 10.0;

  char buf[256];
  size_t n = serializeJson(doc, buf);
  mqtt.publish(TOPIC_DATUAK, buf, n);
  Serial.println(buf);
}

// ---------- Setup / Loop ----------
void setup() {
  Serial.begin(115200);
  pinMode(LED_BERDEA, OUTPUT);
  pinMode(LED_HORIA, OUTPUT);
  pinMode(LED_GORRIA, OUTPUT);
  setLeds("IKASTEN");

  Wire.begin(21, 22);
  if (!mpu.begin()) {
    Serial.println("MPU6050 ez da aurkitu!");
    while (true) delay(1000);
  }
  mpu.setAccelerometerRange(MPU6050_RANGE_4_G);
  mpu.setFilterBandwidth(MPU6050_BAND_94_HZ);

  connectWiFi();
  mqtt.setServer(MQTT_HOST, MQTT_PORT);
  mqtt.setCallback(mqttCallback);
  mqtt.setBufferSize(512);
  mqtt.setKeepAlive(60);   // simulazioaren geldialdi txikiek konexioa ez mozteko
  connectMQTT();

  nextSample = micros();
}

void loop() {
  if (WiFi.status() != WL_CONNECTED) connectWiFi();
  if (!mqtt.connected() && millis() - lastReconnect > 3000) {
    lastReconnect = millis();
    connectMQTT();
  }
  mqtt.loop();

  unsigned long now = micros();
  if ((long)(now - nextSample) < 0) return;
  // Blokeo luze baten ondoren (adib. birkonexioa) ez egin lagin-zaparradarik
  if (now - nextSample > 10 * PERIOD_US) nextSample = now;
  nextSample += PERIOD_US;

  sensors_event_t a, g, t;
  mpu.getEvent(&a, &g, &t);
  float x = a.acceleration.x / G;
  float y = a.acceleration.y / G;
  float z = a.acceleration.z / G;
  tempC = t.temperature;

#if SIMULAZIOA
  // Motor osasuntsua: zarata txikia. Potentziometroa: desoreka (25 Hz = 1500 rpm)
  // eta lerrokatze-akatsa (50 Hz, 2x) simulatzen ditu, 0..1 g.
  float amp = analogRead(PIN_POT) / 4095.0f;
  float ts = now / 1e6f;
  float v = amp * (sinf(2 * PI * 25 * ts) + 0.4f * sinf(2 * PI * 50 * ts));
  x += 0.02f * zarata();
  y += 0.02f * zarata() + 0.3f * v;
  z += 0.02f * zarata() + v;
#endif

  ax[idx] = x; ay[idx] = y; az[idx] = z;
  if (++idx >= N) { idx = 0; prozesatuLeihoa(); }
}

Hurrengoa: Nola dabilen →

Nola dabilen, urratsez urrats

  1. Martxa eta geldialdia: abioak zenbatu

    GPIO 4ko etengailua da agintea. GELDI egoeratik MARTXAra pasatzean, ESP32ak errelea aktibatzen du (GPIO 23) eta abio 1 gehitzen du. Erreleak motorra konmutatzen du: Wokwin, LED urdin bat; muntaketa errealean, 12 V-eko haizagailua.

  2. Takometroa: benetan biratzen du?

    3 edo 4 kableko haizagailuek kable hori bat dute, bira bakoitzeko 2 pultsu ematen dituena. ESP32ak GPIO 19an etenaldi (interrupzio) baten bidez zenbatzen ditu eta segundoro kalkulatzen du:

    rpm = 1 s-ko pultsuak × 60 ÷ 2

    Errelea aktibatuta badago eta, azeleratzeko 3 s-ko tartearen ondoren, motorrak 300 rpm baino gutxiago ematen baditu, errotorea blokeatuta dago. ESP32ak errelea mozten du motorra babesteko, «blokeoak» kontagailuari 1 gehitzen dio, LED gorria keinuka jartzen du eta Node-RED-i abisatzen dio. Berriz armatzeko: GELDI eta berriro MARTXA.

  3. Orduak zenbatu: biratzen duenean bakarrik

    loop()-aren itzuli bakoitzean ESP32ak millis()-ekin neurtzen du zenbat denbora pasatu den eta, motorrak biratzen badu, gehitu egiten du:

    sketch.ino
    bool gira = motorOn && (rpm >= RPM_MIN || ahora - tOn <= T_ARRANQUE);
if (gira) runSec += dt * ESCALA;

    Segundotan zenbatzen du (runSec) eta ordutan erakusten du (÷ 3600). Wokwin ESCALA = 3600: benetako s 1 = motorraren ordu 1, abisuak minututan ikusteko. Muntaketa errealean ESCALA = 1.

  4. Kontua ez galtzea: NVS memoria

    Korrontea kentzean zerora itzultzen den ordu-kontagailuak ez du balio. ESP32ak orduak, abioak eta blokeoak flash memorian gordetzen ditu (NVS, Preferences liburutegia): motorra gelditzean, martxan 60 s-ro, blokeo bat detektatzean eta botoi bat sakatzean. Piztean, balioak irakurri eta zenbatzen jarraitzen du.

  5. Kontagailu bat lan bakoitzeko

    Guztizkoa ez da inoiz ezabatzen. Mantentze-lan bat egiten denean, ESP32ak une horretako orduak (edo abioak) lan horren oinarri gisa gordetzen ditu:

    lanaren erabilera = guztizkoa − oinarria

    Adibidez: motorra 520 h-tan dagoela koipeztatzen da (oinarria = 520). 700 h-tan, koipeztatzeak 250etik 180 h daramatza. Errodamenduek beren oinarriarekin jarraitzen dute.

  6. Plana Node-RED-ek erabakitzen du

    ESP32ak zenbatu baino ez du egiten. Mantentze-plana Node-RED-en dago; horrela, programa ukitu gabe alda daiteke:

    LanaTarteaZer zenbatzen du
    Koipeztatzea250 horduak

    Kontaktorearen/errelearen berrikuspena30 abioabioak

    Lan bakoitzaren erabilera-%a kalkulatzen du: OK % 90etik behera, PROXIMO (hurbil) % 90etik aurrera eta VENCIDO (epea igarota) % 100etik aurrera. Takometroak blokeo bat detektatzen badu, egoera FALLO (matxura) da, eta horrek beste guztiaren gainetik agintzen du.

  7. Jardun: LEDak, OLED-a, abisuak eta liburua

    • Egoera aldatzen denean, Node-RED-ek ESP32ra bidaltzen du (.../prev/egoera, retain-ekin), eta honek dagokion LEDa pizten du eta OLED-ean idazten du.
    • Dashboard-ak lan bakoitzaren erabilera-%aren gauge bat, falta dena, rpm-ak eta kontagailuak erakusten ditu, eta jakinarazpen bat ateratzen du.
    • Mantentze-lana bukatzean, teknikariak «Hecho» (eginda) sakatzen du: Node-RED-ek reset:engrase (adibidez) bidaltzen dio ESP32ari eta mantentze-liburuan idazten du: /data/mantetwin_motor1_preventivo.csv.

void actualizarLeds() {

void publicarDatos() {
  char buf[480];
  int n = snprintf(buf, sizeof(buf),
    "{\"id\":\"motor1\",\"on\":%s,\"rpm\":%.0f,\"fallo\":%s,\"h\":%.3f,\"arranques\":%lu,"
    "\"bloqueos\":%lu,\"escala\":%.0f,\"tareas\":{",
    motorOn ? "true" : "false", rpm, bloqueado ? "true" : "false", runSec / 3600.0,
    (unsigned long)arranques, (unsigned long)bloqueos, ESCALA);
  for (int i = 0; i < N_TAREAS; i++) {
    double uso = tareas[i].porArranques ? (arranques - tareas[i].base)
                                        : (runSec - tareas[i].base) / 3600.0;

  }

  mqtt.publish(T_DATOS, buf);
}

void onMqtt(char* topic, byte* payload, unsigned int len) {
  String msg;
  for (unsigned int i = 0; i < len; i++) msg += (char)payload[i];
  Serial.printf("[MQTT] %s -> %s\n", topic, msg.c_str());

  if (strcmp(topic, T_ESTADO) == 0) {
    int p = msg.indexOf(';');
    estado  = (p < 0) ? msg : msg.substring(0, p);
    mensaje = (p < 0) ? ""  : msg.substring(p + 1);
    actualizarLeds();
    actualizarOled();
  }
  else if (strcmp(topic, T_CMD) == 0) {
    if (msg.startsWith("reset:")) {
      String id = msg.substring(6);
      for (int i = 0; i < N_TAREAS; i++) {
        if (id == tareas[i].id) {
          tareas[i].base = tareas[i].porArranques ? arranques : runSec;
          Serial.printf("[PREV] mantenimiento '%s' realizado\n", tareas[i].id);
        }
      }
      guardarNVS();
    } else if (msg == "borrar_contadores") {
      runSec = 0; arranques = 0; bloqueos = 0;
      for (int i = 0; i < N_TAREAS; i++) tareas[i].base = 0;
      guardarNVS();
      Serial.println("[PREV] contadores a cero (motor nuevo)");
    }
    publicarDatos();
  }
}

void setup() {

}

void loop() {
  if (WiFi.status() != WL_CONNECTED) conectarWiFi();
  if (!mqtt.connected()) conectarMQTT();
  mqtt.loop();

  unsigned long ahora = millis();

  // --- 1. Interruptor MARCHA/PARO (antirrebote) ---
  static bool swAnt = false; static unsigned long tSw = 0;
  bool sw = digitalRead(PIN_SW);
  if (sw != swAnt) { tSw = ahora; swAnt = sw; }
  if (ahora - tSw > 50 && sw != mando) {
    mando = sw;
    if (mando) {
      arranques++;
      bloqueado = false;
      tOn = ahora;
      ponerRele(true);
      Serial.printf("[MOTOR] ARRANQUE n.%lu\n", (unsigned long)arranques);
    } else {
      if (bloqueado) Serial.println("[MOTOR] rearmado");
      bloqueado = false;
      ponerRele(false);
      Serial.println("[MOTOR] PARO");
      guardarNVS();
    }
    publicarDatos();
    actualizarOled();
  }

  // --- 2. Tacometro: rpm cada segundo ---
  if (ahora - tRpm >= 1000) {
    noInterrupts(); uint32_t p = pulsos; pulsos = 0; interrupts();
    rpm = p * 60000.0 / (ahora - tRpm) / PULSOS_VUELTA;
    tRpm = ahora;

    // Rele activado, ya ha pasado el arranque y no gira -> BLOQUEADO
    if (motorOn && ahora - tOn > T_ARRANQUE && rpm < RPM_MIN) {
      bloqueado = true;
      bloqueos++;
      ponerRele(false);                 // proteccion: cortamos el motor
      guardarNVS();
      Serial.println("[MOTOR] *** BLOQUEADO: rele activado pero no gira ***");
      publicarDatos();
    }
  }

  // --- 3. Horas: solo si gira de verdad (o durante el arranque) ---
  double dt = (ahora - tUltimo) / 1000.0;
  tUltimo = ahora;
  bool gira = motorOn && (rpm >= RPM_MIN || ahora - tOn <= T_ARRANQUE);
  if (gira) runSec += dt * ESCALA;

  // --- 4. Tareas periodicas ---
  if (ahora - tPub > 2000)  { tPub = ahora;  publicarDatos(); }
  if (ahora - tOled > 500)  { tOled = ahora; actualizarOled(); }
  static unsigned long tLed = 0;
  if (ahora - tLed > 100)   { tLed = ahora;  actualizarLeds(); }
  if (motorOn && ahora - tGuardar > 60000) { tGuardar = ahora; guardarNVS(); }
}

    Igo eta jaitsi MARTXA etengailua 27 bat aldiz: 27 abiotara (% 90) PROXIMO egoerara pasatzen da, eta 30era, VENCIDO egoerara. Sakatu «Contactor revisado».

  1. Pasatu motor errealera

    • Sketch-ean: #define WOKWI 0, ikasgelako WiFi-a eta MQTT_HOST-en Mosquitto duen zerbitzariaren IPa. ESCALA 1 da orduan (denbora erreala). Klaserako, adibidez, ESCALA 60 jar daiteke: benetako min 1 = ordu 1.
    • Errelea: iturriaren +12 V → COM, NO → haizagailuaren +, haizagailuaren − → iturriaren GND.
    • Takometroa: kable horia → GPIO 19, 10 kΩ-eko erresistentzia 3V3ra (irteera kolektore irekikoa da). Inoiz ez 5 V edo 12 V-era.
    • 12 V-eko iturriaren GND-a ESP32aren GND-arekin lotu behar da; bestela, pultsuak ez dira iristen.
    • Haizagailua 2 kablekoa bada, ez du takometrorik: sentsore optiko bat edo Hall efektukoa beharko litzateke.
    • GPIO 18 eta BLOKEO etengailua ez dira erabiltzen. Benetako blokeo bat probatzeko, gelditu palak arkatz batekin, inoiz ez hatzarekin.
